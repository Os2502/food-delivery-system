# Информационная система доставки готовой еды

Проект посвящён разработке информационной системы для автоматизации бизнес-процессов компании по доставке готовой еды. Система предназначена для упрощения обработки заказов, взаимодействия с клиентами и организации доставки.

## Структура проекта

- `docs/Актуальность.docx` — обоснование актуальности проекта.
- `docs/Функциональные требования.docx` — функциональные требования к системе.
- `docs/Нефункциональные требования и сценарии.docx` — нефункциональные требования и сценарии использования.
- `docs/Архитектура.docx` — архитектура системы.
- `docs/Описание классов и диаграмма последовательности.docx` — описание классов и диаграмма последовательности.
